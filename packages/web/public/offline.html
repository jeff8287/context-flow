서버가 꺼져 있습니다

이 주소에서 답이 없습니다. 맥락 흐름의 화면은 이 컴퓨터에서 도는 서버가 내줍니다. 서버가 뜨면 이 창이 저절로 이어집니다.

  1. 늘 띄워 두도록 설치했다면저장소 폴더에서 npm run service -- status로 상태를 보고 npm run service -- restart로 다시 띄웁니다.
  2. 아직 설치하지 않았다면저장소 폴더에서 npm run service -- install을 한 번 돌리면 로그인할 때마다 저절로 뜹니다. 이번만 띄우려면 npm run serve입니다.
  3. 데모를 보던 중이었다면npm run demo를 다시 돌립니다.

다시 잇는 중입니다
